# API contract snapshot

`openapi.json` is the OpenAPI document generated by the backend
(`backend/api/src/Infrastructure/OpenApi/FallGuardianOpenApiFactory.php` plus
API Platform resources). It is committed so every API contract change is
visible in pull-request diffs and can be reviewed against the mobile and watch
clients.

Regenerate it whenever the API surface changes:

```sh
make up              # or any running backend stack
make openapi-export  # writes packages/api_contract/openapi.json
```

API CI regenerates the snapshot from the test stack and fails if it differs
from the committed file. Do not edit `openapi.json` by hand.
